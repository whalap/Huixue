03使用指南（电脑端 & iPad 端）

💻电脑端（Windows / Mac）

  1. 用 Chrome 或 Edge 浏览器打开 html 文件（双击文件 → 选择浏览器；或将文件拖进浏览器窗口）。
  2. 首次打开若浏览器询问，选择始终允许网页发声；确保电脑音量已开。
  3. 页面上方工具栏可切换语速（0.5×–1.5×）与发音人（优先选 English / en-GB 语音，如 Google UK English Female）。
  4. 点任意单词 / 音节听发音；课文可逐句点读或整篇连读；小测与填空全部点选作答。
  5. 八个单元文件与总目录放在同一文件夹，从总目录点「进入学习」即可相互跳转。
✓ Chrome / Edge 内置网络语音，通常无需额外安装即可发音

📱iPad 端（iPadOS Safari）

  1. 方式一 · 隔空投送（AirDrop）：电脑上右键文件 → 共享 → 隔空投送到 iPad → 接收后用 Safari 打开。
  2. 方式二 · 微信 / 文件传输：把 html 文件发到 iPad → 保存到「文件」App → 长按文件 → 共享 → 「用 Safari 打开」。
  3. 必须用 Safari 或 Chrome 打开，「文件」App 里的预览不能交互（点读和练习都用不了）。
  4. 如点发音没声音：检查 iPad 侧边静音键与音量，再按下方「安装发音音色」下载英语语音。
⚠ iPadOS 14.5 及以上版本才完整支持点读发声；过旧的系统请先升级。

04如何安装发音音色（让朗读更标准）

iPad / iPhone（iOS）

设置 → 辅助功能 → 朗读内容 → 声音
  1. 打开「设置」→「辅助功能」→「朗读内容」→「声音」。
  2. 在「English」列表中选择并下载一个语音，推荐 Samantha（英式）或 Daniel（英式男声）。
  3. 下载后回到学习页刷新，在「发音人」下拉框中选择该语音，发音会更清晰、标准。
  4. 也可在「朗读内容」里打开「朗读屏幕」，双指从屏幕顶部下滑即可整页朗读（作为辅助功能）。

电脑（Windows / Mac）

Windows：设置 → 时间和语言 → 语音；Mac：系统设置 → 辅助功能 → 朗读内容
  1. Windows：设置 →「时间和语言」→「语音」→ 管理语音 → 添加 English (United Kingdom) 语音包；或直接在 Chrome 里选择自带的 Google UK English Female。
  2. Mac：系统设置 →「辅助功能」→「朗读内容」→「系统声音」→ 选择 English 语音（如 Daniel）。
  3. 多数情况下 Chrome / Edge 自带英音语音，打开页面即可点读，无需任何安装。
📌 小提示：学习页已针对手机 / iPad 做适配（按钮加大、触控区域 ≥ 44px）。把总目录与 8 个单元文件放在同一文件夹并一起传输到 iPad，总目录里的「进入学习」按钮才能正常跳转。
