02怎么走这条网络三条路径，按学生情况选一条

跟着课本走

适合：在校生，进度跟学校单元走
  1. 进课本同步线，按当前单元看点读页
  2. 用单词闪卡过一遍本单元词汇
  3. 课后做精简练习页，错的点记下来
  4. 周末进语法线，补本单元对应的语法点
课本是主线，语法和跟读是副线

补语法底子

适合：语法薄弱、写作老出错
  1. 进语法线，从 A1 第一个知识点开始
  2. 七组全过 → ★，卡住就退回上一组
  3. 做完输出练习，给自己句子打星级
  4. 错题进 SRS，按提醒日子回头重练
一次只练一个点，不贪多

冲中考听说

适合：初二 / 初三，备考人机对话
  1. 进中考 E 听说线，先做官方全真模拟定水平
  2. 按给分找弱项题型，进对应分级题库
  3. A1 打基础 → A2 同步 → B1 拔高，每关 100 题
  4. 弱项回跟读线练发音，回课本线补词汇
